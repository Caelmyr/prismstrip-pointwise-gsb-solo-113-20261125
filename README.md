# PrismStrip 窄带光谱测读台

查看相机拍下的一维色散条带。用两个已知波长点为原片的 X 建立线性换算。强度是来自相机图像的相对数值。

1. 打开标明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 填原片左右标记和两个已知波长、采样上下行。原片点读显示波长与实际亮度，标定外不估读。
3. 「取光带」后点图再保存即可更新取样列。给窗口半宽和背景亮度，读真实范围内背景以上的列信号合计。
4. 取样窗同时罩住两条亮线时自动尝试分读：两峰中心至少隔四个原片列、各自有至少三个连续背景以上列、分界取两峰之间实拍低谷（低谷与左右相邻列都低于较弱峰，孤立掉亮的一格不作分界）。证据不足时提示“双线还分不开”，仍保留原合读。
5. 分读成功后按原片 X 把窗口列整列归左/右（分界列归左），沿用同一背景扣除，两带信号合计等于原窗口信号；点读原片会标明该列属于哪一带，PNG 校样、CSV 与证据 ZIP 标出同一分界和两带读数及峰位波长。
6. 下载实际列剖面 CSV、原片标注 PNG 或证据 ZIP，或将该原照直接转入照片准备。

`docker compose up --build -d --wait` 默认监听本机 19916。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后运行 `./start.sh`。数据保存在独立卷或本地数据目录。
